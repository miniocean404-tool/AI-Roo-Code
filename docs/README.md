## 项目概览

**Roo Code** 是一个功能强大的 VS Code AI 编程助手扩展：

- **多模式系统**: Code、Architect、Ask、Debug、Custom
- **多 AI 提供商**: 支持 30+ 提供商
- **MCP 集成**: Model Context Protocol 支持
- **代码索引**: 向量搜索和语义搜索
- **国际化**: 支持 18 种语言

## 技术栈

| 层级 | 技术 |
|------|------|
| 包管理 | pnpm + workspace |
| 构建系统 | Turbo + ESBuild |
| 扩展后端 | TypeScript + Node.js |
| 前端 UI | React + Vite + Tailwind |
| 测试框架 | Vitest |
